# MY STUDY HELPER 📚️
I created this project to help me memorize and study more effectively.
I design it based on my needs, and some additional features to make it effective for anyone.
i gave it various features including modes to make it more organized and easy to navigate and work with.

# FEATURES✨️
## LEARNING MODE:
  * **Summarize:** there is an option where u can summarize the text or file u uploaded so you get an overview about the topic, and find it easier to work with.
  * **Mindmap:** this is so helpful whereby you can visualize the important part and ignore additional details, and check on them once u get a good understanding of the key concepts.
  * **Understand:** in my opinion, this is so useful, and i rarely find it in some learning app or websites as built-in feature. I think that by asking questions u get the most out of the topic and remove uncertainties, therefor i did this feature, where you can ask questions and you get answers.

## PRACTICE MODE:
   * **FlashCards:** A famous way to get definitions and key concepts memorized, i think it is functional and helps memorize long-term, so having flashcards as a feature where u can get them automatically instead of manually writing each one is a good think to have.
   * **MCQ:** this makes it easier to answer to questions even if you didn't memorize the topic well yet, because there is the answer whithin the choices so you can easly spot it.
   * **Q&A:** A more advanced feature, to get this you should have a better understanding of the topic. Done so you can change practice exericeses as you progress.

# TECH STACK🧑‍💻️
* **App Framework**: Streamlit (for UI and backend logic)
* **AI Engine**: Meta Llama 3.1 (accessed via Hugging Face Inference API)
* **Environment Management**: `python-dotenv` (to securely load API tokens)
* **Language**: Python

# HOW TO RUN▶️
1. Clone this repository.
2. Install dependencies. _check the `requirements.txt` in this repository which contains all the requirements._
3. Create a .env file in the root directory and add your Hugging Face token.
4. then run it with this cmd:
`streamlit run your_filename.py`
